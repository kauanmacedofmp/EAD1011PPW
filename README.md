# Mundo dos Games

## Respostas para a atividade

**1. Qual é a função do HTML na página desenvolvida?**  
O HTML organiza o conteúdo e a estrutura da página, como títulos, parágrafos, imagens, links, botões, listas e seções.

**2. Onde você utilizou CSS e quais as alterações que realizou?**  
O CSS foi utilizado no arquivo `style.css`. Ele altera as cores, o fundo, as fontes, os tamanhos, os espaçamentos, as bordas, os cartões e os botões. Também adapta o layout para celulares.

**3. Onde você utilizou JavaScript e o que acontece quando ele é executado?**  
O JavaScript foi utilizado no arquivo `script.js`, no botão “Recomendar um jogo”. Quando o visitante clica nele, um jogo é escolhido aleatoriamente e aparece na página.

**4. Qual é a principal diferença entre CSS e JavaScript?**  
O CSS controla a aparência visual da página, enquanto o JavaScript adiciona comportamento e interatividade.
